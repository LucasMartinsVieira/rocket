# Getting started

## Install Rocket on Android

1. Open [GitHub Releases](https://github.com/LucasMartinsVieira/rocket/releases).
2. If a release has a `.apk` under **Assets**, download it and open it on your phone. Android may ask you to allow installation from the app you downloaded it with.
3. If there is no APK, follow the [development guide](development.md#build-an-android-apk) to build one.

When updating, install a compatible APK over your current copy. **Don't uninstall Rocket just to update it:** its library is stored locally. [Export a backup](backup-and-restore.md) first if you're switching builds or moving to another phone.

## Add your first title

1. Open **Library → Add title**.
2. Choose a media type and enter the title. Add any other details you want. You can also use [catalog lookup](catalog-lookup.md) to fill in metadata.
3. Choose a status and tap **Save**. To track when you started or finished a title, fill in either or both personal dates. They don't change the status automatically.

Your library starts empty and is usable offline. Next, learn how to [organize titles into lists](library.md).
