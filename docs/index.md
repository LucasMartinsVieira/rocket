# Rocket documentation

Rocket is a personal Android library for anime, manga, movies, TV shows, books, and games. Your library lives on your device, and you don't need an account to use it.

## Using Rocket

| Guide | What it covers |
| --- | --- |
| [Getting started](getting-started.md) | Install Rocket and add your first title. |
| [Library and lists](library.md) | Browse, filter, take notes, and reorder a list. |
| [Catalog lookup](catalog-lookup.md) | Find titles online and set up optional provider credentials. |
| [Backup and restore](backup-and-restore.md) | Export a copy of your library or restore it on another device. |
